# Interactive Dashboard Development

## Overview

This project presents an interactive dashboard that displays business performance using sales data. The dashboard provides key insights through charts, performance metrics, and filters to support data-driven decision-making.

---

## Features

- Interactive dashboard using Streamlit
- Sales performance metrics
- Monthly sales bar chart
- Monthly profit line chart
- Month-wise filtering
- Data table visualization

---

## Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib

---

## Project Structure

```
Interactive_Dashboard_Development/
│── sales_data.csv
│── app.py
│── requirements.txt
│── README.md
```

---

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

---

## Run the Project

```bash
streamlit run app.py
```

---

## Dashboard Components

- Total Sales
- Total Profit
- Total Customers
- Monthly Sales Chart
- Monthly Profit Chart
- Interactive Month Filter
- Sales Dataset Table

---

## Project Outcome

The dashboard provides a simple and interactive way to analyze business performance. Users can explore monthly sales and profit trends, view key performance indicators, and filter data to gain meaningful insights for better decision-making.
